# Cherry Blossom

**Hardware design, beautifully reimagined.**

Cherry Blossom is an AI-native PCB design tool — a modern, fast, open alternative to legacy EDA software.

Describe a circuit in plain English, refine it visually or in code, and order the board. All in one app.

## What we're building

- **AI-powered schematics** — Generate working circuits from a prompt, then iterate in chat or by hand.
- **Code, not binaries** — Designs are plain-text TSX. Diff them, review them, version them like any other code.
- **Native speed** — Built in Rust + Tauri. Sub-second startup on macOS, Windows, and Linux.
- **End-to-end flow** — Schematic, PCB layout, 3D preview, DRC, and JLCPCB ordering in one place.
- **Open source** — MIT-licensed, built on [tscircuit](https://github.com/tscircuit/tscircuit).
